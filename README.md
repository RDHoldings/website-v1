# Red Domino Holdings - Website

A premium, responsive Single Page Application (SPA) landing page for Red Domino Holdings.

## Tech Stack

- **React** (Vite)
- **Tailwind CSS**
- **Framer Motion**
- **Lucide React**

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Fonts

Pirulen and Felix Titling are loaded from `src/assets/fonts/` (copied from your system). If fonts don't load, ensure these files exist:

- `src/assets/fonts/Pirulen Rg.otf`
- `src/assets/fonts/FELIXTI.TTF`
